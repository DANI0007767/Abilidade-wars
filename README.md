# Habilit Wars - Display de Habilidades

Script para Roblox que mostra a habilidade de cada jogador acima da cabeça.

## 🚀 Como Usar

### Via Executor (Recomendado)
```lua
.loadstring(game:HttpGet('https://raw.githubusercontent.com/DANI0007767/Habilit-wars/main/executor.lua'))()
```

### Manual
1. Copie o código de `executor.lua`
2. Cole no seu executor favorito
3. Execute e veja as habilidades acima da cabeça de cada jogador!

## ✨ Funcionalidades

- 🔍 **Detecção automática** de habilidades (Tools, Attributes, Values)
- 🎯 **Exibição visual** acima da cabeça (BillboardGui)
- 🔄 **Atualização em tempo real** a cada 0.5 segundos
- 👥 **Suporte múltiplos jogadores**
- 🎮 **Compatível com Ability Wars** e similares

## 📦 Arquivos

- **executor.lua**: Versão compacta para uso direto
- **logicaHabilit.lua**: Código completo com comentários
- **GuiHabilit.lua**: Interface para botões (em desenvolvimento)

## 🛠️ Como Funciona

1. **Exploração**: Detecta onde o jogo guarda as habilidades
2. **Exibição**: Cria texto flutuante acima da cabeça
3. **Atualização**: Monitora mudanças de habilidade
4. **Formato**: Exibe "Nome do Jogador\nHabilidade Atual"

## ⚠️ Importante

- Use com responsabilidade
- Testado em Ability Wars
- Pode não funcionar em jogos com proteção anti-script
